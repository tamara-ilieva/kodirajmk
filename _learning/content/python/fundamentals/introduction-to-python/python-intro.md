Во претходната лекција видовме како идејата за решавање задача се претвора во инструкции. Сега ќе ги запишеме тие инструкции во Python и ќе видиме што се случува кога ги извршуваме.

## Што е Python?

**Python** е програмски јазик за општа намена. Со него можеш да автоматизираш задачи, да обработуваш податоци и да развиваш веб-апликации. На пример, со Python можеш да го пресметаш просекот на оценките од табела или да преименуваш повеќе датотеки по исто правило.

Начинот на кој се пишува кодот во еден програмски јазик се нарекува **синтакса**. Во оваа лекција ќе научиш две правила од синтаксата на Python: како се запишува текст и како се повикува функција.

## Твојата прва програма

Притисни **Изврши** во уредувачот за да го извршиш примерот.

```python-editor
print("Здраво, свету!")
```

- `print` е вградена функција што прикажува вредности на екранот.
- Заградите `()` означуваат повик на функцијата. Меѓу нив стои вредноста што сакаме да ја прикажеме.
- Наводниците означуваат дека `"Здраво, свету!"` е текстуална вредност. Во излезот се прикажува текстот без наводниците.

**Python интерпретерот** е програмата што го извршува кодот. Во оваа лекција тој работи во прелистувачот. Резултатот што го прикажува `print()` се нарекува **излез**.

## Текст и пресметки

```python-editor
print("2 + 3")
print(2 + 3)
```

Интерпретерот ги извршува овие два реда по редослед. Во првиот ред, наводниците му кажуваат да го прикаже текстот `2 + 3`. Во вториот ред, интерпретерот го пресметува изразот `2 + 3` и го предава резултатот `5` на `print()`. Секој повик во примерот прикажува една линија.

:::predict Предвиди го излезот
Што ќе прикаже `print(4 * 3)`? Во Python, `*` е знакот за множење.

- [ ] 4 * 3
- [x] 12
- [ ] 7
:::

## Поправи синтаксичка грешка

Во примерот недостига завршниот наводник. Изврши го кодот, прочитај ја пораката за грешка и додај го наводникот. Потоа изврши го кодот повторно.

```python-editor
print("Добредојде!)
```

Пораката `SyntaxError` значи дека кодот прекршува правило на синтаксата. Во овој пример, текстот треба да заврши со наводник пред затворачката заграда.

## Практична вежба

:::practice Напиши поздрав и прикажи резултат
Промени го поздравот за да го вклучиш своето име. Во нов ред додај повик на `print()` што го пресметува и прикажува збирот на 7 и 5. Провери дали излезот има два реда и дали во вториот пишува `12`.

```python-editor
print("Здраво!")
```

:::solution Прикажи едно решение
```python
print("Здраво, Ана!")
print(7 + 5)
```
:::
:::

:::
