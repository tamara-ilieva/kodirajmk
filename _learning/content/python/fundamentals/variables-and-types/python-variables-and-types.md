Во претходната лекција користевме `print()` за да прикажеме текст и резултати од пресметки. Кога на некоја вредност ќе ѝ дадеме име, можеме повторно да ја користиме во програмата.

## Задавање вредност

```python-editor
name = "Ана"
points = 10

print(name)
print(points)
```

Во редот `points = 10`, знакот `=` ја задава вредноста `10` на променливата `points`. Кога ќе напишеш `print(points)`, Python ја прикажува вредноста. Пробај и со `print("points")`. Со наводници, Python ќе го прикаже зборот `points` како текст.

Замисли ја променливата како име што покажува кон кутија со вредност. Типот ѝ припаѓа на вредноста. На пример, `points` покажува кон `10`, чиј тип е `int`.

```text Шематски приказ
         ┌──────────────┐
points → │ Вредност: 10 │
         │ Тип: int     │
         └──────────────┘
```

### Може ли кутијата да биде празна?

Во Python не можеш да создадеш променлива со „празна кутија“. Некои јазици дозволуваат да декларираш променлива без почетна вредност. Во Python, ако ја извршиш следнава линија пред да му зададеш вредност на `score`, ќе добиеш `NameError`.

```python-editor
print(score)
```

Додај `score = None` над `print(score)` и изврши го примерот повторно. Сега ќе се прикаже `None`. Тоа е посебна вредност со тип `NoneType` што можеш да ја употребиш кога сè уште немаш резултат.

Користи описни имиња, како `points` или `total_points`. За примерите во курсот ќе користиме мали латинични букви и долна црта меѓу зборовите. Име на променлива може да содржи цифри по првиот знак. Python прави разлика меѓу големи и мали букви, па `points` и `Points` се различни имиња.

## Менување вредност

```python-editor
points = 10
points = points + 5
print(points)
```

Python прво ја пресметува десната страна на `=`. Ја зема тековната вредност `10`, додава `5` и потоа ја задава новата вредност `15` на `points`.

:::predict Предвиди ја вредноста
Ако во примерот го замениш редот `points = points + 5` со `points = 5`, што ќе прикаже програмата?

- [ ] 10
- [ ] 15
- [x] 5
:::

## Основни типови

Типот на вредноста одредува кои операции можеш да ги примениш врз неа. На пример, `+` собира броеви, а кај два текста ги спојува.

| Тип | Што претставува | Пример |
| --- | --- | --- |
| `int` | Цел број | `10` |
| `float` | Број со подвижна запирка | `19.5` |
| `str` | Текст | `"Ана"` |
| `bool` | Логичка вредност | `True` или `False` |

Кај децималните броеви во кодот се пишува точка, како во `19.5`. Логичките вредности `True` и `False` почнуваат со голема буква.

Со `type()` можеш да го провериш типот на вредноста. Изврши го примерот и спореди ги последните два реда од излезот.

```python-editor
print(type(10))
print(type(19.5))
print(type(True))
print(type("10"))
```

Излезот за `"10"` е `<class 'str'>`. Наводниците означуваат текст дури и кога во него има само цифри.

## Претворање текст во цел број

За да собереш `"10"` и `5`, прво претвори го текстот во цел број со `int()`. Потоа можеш да ја користиш добиената вредност во пресметката.

```python-editor
points_text = "10"
points = int(points_text)
print(points + 5)
```

:::note
За `int("Ана")`, Python ќе пријави `ValueError` бидејќи текстот не претставува цел број.
:::

## Практична вежба

:::practice Пресметај вкупно поени
Во првиот круг Ана освоила 12 поени, а во вториот 8. Вредноста за вториот круг е запишана како текст. Претвори ја во цел број, зачувај го збирот во `total_points` и прикажи го. Очекуваниот резултат е `20`.

```python-editor
first_round = 12
second_round = "8"
```

:::solution Прикажи едно решение
```python
first_round = 12
second_round = "8"
total_points = first_round + int(second_round)
print(total_points)
```
:::
:::

:::summary Што научи?
Со `=` задаваш вредност на променлива. Со `type()` го проверуваш типот на нејзината тековна вредност. Со `int()` можеш да претвориш текст што претставува цел број во број за пресметка.
:::
